# Remedy Tech Zone - Futuristic One-Page Website Template

A modern, high-tech, responsive website design template built for **Remedy Tech Zone - The Field Guide for Better Tools**.

This codebase perfectly implements the sleek cyberpunk dark aesthetic with neon cyan and emerald accents, interactive category filtering, side-by-side article cards, pop-out article reading modals, and modular code architecture.

---

## 🚀 Features

- **Futuristic High-Tech UI:** Dark deep space palette `#030712`, glowing emerald `#00ff88` and cyan `#00f2fe` highlights.
- **Hero Showcase:** High-impact heading, SVG technology illustrations, and glowing tech sidebar rail.
- **Side-by-Side Article Cards:** Responsive 3-column article layout with category tags, dates, and clean typography.
- **Interactive Category Filter Bar:** Filter articles dynamically between *All*, *Smart Rings*, *Meta Smart Glasses*, and *Smartwatches*.
- **Pop-Out Modal Feature:** Clicking "Read More" opens a responsive modal with article full text and smooth glassmorphism backdrop.
- **"+ More Articles" Loader:** Seamlessly loads additional articles dynamically without page reloads.
- **About Remedy Tech Zone Section:** Visual highlight frame and feature value proposition icons (*Trusted Insights*, *Practical Guides*, *Better Decisions*).
- **Matching Footer:** Complete with branding, quick links, social media icons, and smooth "Back to top" navigation.
- **100% Mobile Responsive:** Adapts flawlessly to phones, tablets, and desktops.

---

## ⚙️ Quick Start

1. **Clone or Download** this repository.
2. Open `index.html` in any web browser.
3. No build tools or node dependencies required — it works directly out of the box!

---

## 🎨 Customization

- **Colors & Branding:** Edit the CSS custom properties in `styles.css` under `:root`.
- **Articles & Content:** Modify or add articles inside the `articlesData` and `extraArticles` objects in `script.js`.
